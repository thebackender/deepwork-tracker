# deepwork-tracker

Track deep work sessions on the way to 10,000 hours. Python (standard library only), a Markdown log, git, and an animated statistics page in the browser.

## Usage

```
dw add 90 thesis "Wrote chapter 2 intro"   # add a record in one line
dw add                                     # or answer prompts for each field
dw stats                                   # open the statistics page
```

- Records go to `deepwork_logs.md` and are committed to git automatically.
- The time is the session's **start** time: `dw add 90 …` at 11:00 records `09:30`.
- To fix or delete a record, edit `deepwork_logs.md` by hand. The next `dw add` commits your edits first, as "Manual edits". Keep the table at the end of the file, since new rows are added at the bottom.

## Setup

Needs Python 3.8+ and git.

- **Linux / macOS:** add to `~/.bashrc` or `~/.zshrc`:
  `alias dw="python3 /path/to/deepwork-tracker/dw.py"`
- **Windows:** add the project folder to your `PATH`, and `dw.bat` will make `dw` work.

## Files

| File | What it is |
|---|---|
| `deepwork_logs.md` | Your records (created on the first `dw add`) |
| `dw.py` | `add` and `stats` commands. Only `read_records()` / `write_record()` know the file format. |
| `web/` | Statistics page: `index.html`, `style.css`, `app.js` (no libraries) |
| `web/data.js` | Generated by `dw stats`, not committed |
